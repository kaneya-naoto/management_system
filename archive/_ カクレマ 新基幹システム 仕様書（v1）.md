# カクレマ 新基幹システム 仕様書（v1）

## 1. 目的

* 個室麻雀店「カクレマ」における
  **予約・清掃業務・人員管理の属人化排除**
* FC展開を前提とした
  **店舗単位で完結するCMS基幹システムの構築**
* LINEを活用した
  **清掃業務の自動募集・延長対応・急募対応の自動化**

---

## 2. システム全体構造

### 2.1 組織構造（固定）

```
統括本部
└ オーナー
   └ 実店舗（CMS）
```

* **拠点・エリア概念は持たない**
* 実店舗は **1 CMS = 1 店舗**
* 同一建物・同一人員で運営される複数区分（例：東口 / プレミアム）は
  **「内部営業区分」として実店舗配下で管理**

---

## 3. アカウント・権限仕様

### 3.1 アカウント種別

| 種別   | 操作可能範囲             |
| ---- | ------------------ |
| 統括本部 | 全オーナー / 全実店舗の閲覧・操作 |
| オーナー | 自オーナー配下の実店舗のみ      |
| 実店舗  | 自店舗CMSのみ           |

※ 権限は **表示可 / 編集可 / 設定可** を内部的に分離可能な設計とする

---

## 4. 実店舗（CMS）機能仕様

### 4.1 内部営業区分（必須）

* 実店舗は **1つ以上の内部営業区分を持つ**
* 例

  * 池袋東口
  * 池袋東口プレミアム

#### 内部営業区分の役割

* 清掃者が **現場を判別するための識別**
* 売上・予約・案件・鍵番号を **区分別に集計・管理**

---

## 5. 予約管理

### 5.1 予約流入経路

| 経路        | 処理       |
| --------- | -------- |
| サイト予約フォーム | 自動反映     |
| LINEトーク予約 | CMSへ手動入力 |
| 電話 / 直接   | CMSへ手動入力 |

---

### 5.2 予約データ項目（必須）

* 利用時間
* 利用日
* 利用者名
* メールアドレス
* 電話番号
* 内部営業区分ID
* 予約ステータス

---

## 6. 予約システム仕様（フロント）

### 6.1 フロー

```
予約フォーム入力
→ クレジットカード決済
→ 予約完了ページ
→ 予約確認メール送信
```

### 6.2 予約完了ページ仕様

* 表示文言：

  * 「このメールアドレスに予約情報を送信しました」
* 表示項目：

  * 登録メールアドレス
* 機能：

  * メールアドレス編集
  * 再送ボタン

#### メール修正時の挙動

* 修正前メールアドレス宛の予約情報は **無効化**
* 再送は修正後アドレスのみに送信

---

## 7. 鍵番号管理

### 7.1 基本仕様

* 実店舗 × 内部営業区分ごとに

  * 鍵番号を複数（例：10個）登録可能
* 予約確定時：

  * 鍵番号を **ランダムで1つ割当**
  * 予約時間帯で **一時ロック**

### 7.2 競合防止

* 同一時間帯に同一鍵番号が
  **複数予約に割り当てられない設計**

---

## 8. 清掃案件管理

### 8.1 案件生成

* 予約確定時に **清掃案件を自動生成**
* 案件には必ず以下を紐付ける：

  * 実店舗ID
  * 内部営業区分ID
  * 清掃予定時間
  * 注意事項

---

## 9. LINE（清掃応募者）仕様

### 9.1 LINE公式

* 清掃業務応募者専用LINE公式アカウント
* 応募者は **初回登録時に店舗を選択**

### 9.2 初回フロー

```
LINE登録
→ プロフィール登録
→ iPass発行
→ 応募画面
```

### 9.3 2回目以降

* iPass入力のみで応募画面へ遷移

---

## 10. 応募・固定者フロー

### 10.1 固定者管理（店舗単位）

* 店舗ごとに固定者を登録可能
* 案件発生時：

  1. 固定者へ優先通知
  2. OK → 担当確定
  3. NG → LINEへ自動公募

---

## 11. シフト管理

* 案件 × 清掃者をマージ表示
* 未応募・未充足案件が一目で分かるUI
* 担当確定後はシフトに反映

---

## 12. 延長対応（特例）

### 12.1 フロー

```
店舗設置QR
→ 延長フォーム
→ オーナー＆担当清掃者へ通知
→ 担当者 YES / NO
```

* NO の場合：LINEに【急募】通知

### 12.2 追加報酬ルール（仮）

* 延長 **1時間ごとに基本報酬の50%を加算**
* 端数・上限は今後の仕様で確定予定

---

## 13. 清掃支払い管理

* 案件単位で以下を管理：

  * 担当清掃者
  * 基本報酬
  * 延長加算
  * 支払いステータス
* 店舗単位で集計・確認可能

---

## 14. 売上・KPI管理

* 実店舗単位
* 内部営業区分別に算出可能

  * 売上
  * 稼働率
  * 清掃コスト
  * 粗利

---

## 15. ログ・監査

* 操作ログ
* 通知履歴
* メール送信履歴
* 鍵番号割当履歴

---

## 16. 非要件（v1では対応しない）

* 自動給与振込
* 外部会計ソフト連携
* 多言語対応
* オフライン運用

---

## 17. 実装上の注意（重要）

* **内部営業区分は将来「独立店舗」に昇格可能なID設計**
* データ削除は原則禁止（論理削除）
* FC展開を前提とした **データ分離性の担保**
