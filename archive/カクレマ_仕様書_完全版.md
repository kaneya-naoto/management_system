## 1. プロジェクト概要

### システム名
**カクレマ 新基幹システム**

### コンセプト
カクレマ専用の予約・清掃業務・人員管理システム
- 予約・清掃業務・人員管理の属人化排除
- FC展開を前提とした店舗単位CMS構築
- LINEを活用した清掃募集/延長対応/急募の自動化

### 開発規模
| 項目 | 内容 |
|------|------|
| 総工数 | 12人日 |
| 想定期間 | 約2.5週間（12営業日） |
| 担当 | SE 1名 |

### ビジネス要件
- **予約管理**: Webフォーム予約→決済→自動反映、LINE/電話予約→手動入力
- **清掃案件管理**: 予約確定時に自動生成、LINE連携で清掃者募集
- **鍵番号管理**: 予約確定時にランダム割当、同一時間帯の競合防止
- **固定者・急募**: 優先通知フロー、条件該当で【急募】配信
- **延長対応**: QR→延長フォーム→担当者通知、報酬自動計算
- **支払い管理**: 案件単位の支払い管理、店舗単位で集計
- **売上・KPI**: 区分別の売上/稼働率/清掃コスト/粗利

## 3. 権限モデル

### 3階層構造

| レベル | 種別 | 操作範囲 |
|--------|------|----------|
| 3 | 統括本部 (HQ) | 全店舗 |
| 2 | オーナー (OWNER) | 自オーナー配下店舗 |
| 1 | 店舗 (STORE) | 自店舗のみ |

### 組織階層

```
統括本部
└ オーナー（契約・請求主体）
    └ 実店舗（CMS 1つ = 1店舗）
        └ 内部営業区分
           - 例：池袋東口
           - 例：池袋東口プレミアム
```

### 認証方式

**CMS側**
- メール + パスワード
- パスワードリセット（メールでリンク送信）
- セッション管理（PHPセッション）

**清掃者（LINE）**
- LINE UserIDで自動識別
- 初回プロフィール登録必須

## 4. 主要機能仕様

### 4.1 予約管理
- サイト予約フォーム → 決済 → 自動反映
- LINE/電話予約 → CMSへ手動入力
- 予約完了ページでメールアドレス編集・再送可能
- 予約ステータス: pending → confirmed → completed / cancelled

### 4.2 鍵番号管理
- 区分ごとに複数の鍵番号を登録
- 予約確定時にランダム割当
- 同一時間帯の競合防止（悲観的ロック）

### 4.3 清掃案件管理
- 予約確定時に自動生成
- 状態遷移：unassigned → recruiting → assigned → completed → paid

### 4.4 LINE連携（清掃応募者）
- LINE UserIDで自動識別
- 初回：LINE登録 → プロフィール登録 → 応募画面
- 2回目以降：自動認識
- 案件URLをPush通知

### 4.5 固定者・急募
- 固定者へ優先通知 → NG時はLINE公募
- 条件該当で【急募】Push配信

### 4.6 延長対応
- QR → 延長フォーム → 担当者に通知
- YES: 案件更新 / NO: 急募通知へ
- 延長1時間ごとに基本報酬の50%加算

### 4.7 シフト・支払い管理
- 案件×清掃者マージ表示
- 店舗単位で集計・支払い管理

### 4.8 売上・KPI
- 区分別：売上/稼働率/清掃コスト/粗利

### 4.9 ログ・監査
- 操作ログ/通知履歴/メール履歴/鍵割当履歴

### 5.3 主要テーブル定義

#### users（CMSユーザー）
```sql
CREATE TABLE users (
  id BIGINT NOT NULL AUTO_INCREMENT,
  email VARCHAR(255) NOT NULL,
  password VARCHAR(255) NOT NULL,
  name VARCHAR(100) NOT NULL,
  role ENUM('HQ', 'OWNER', 'STORE') NOT NULL DEFAULT 'STORE',
  status ENUM('active', 'inactive', 'suspended') NOT NULL DEFAULT 'active',
  last_login_at DATETIME NULL,
  password_changed_at DATETIME NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at DATETIME NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_users_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### reservations（予約）
```sql
CREATE TABLE reservations (
  id BIGINT NOT NULL AUTO_INCREMENT,
  store_id BIGINT NOT NULL,
  sales_area_id BIGINT NOT NULL,
  customer_name VARCHAR(100) NOT NULL,
  customer_email VARCHAR(255) NOT NULL,
  customer_phone VARCHAR(20) NOT NULL,
  reservation_date DATE NOT NULL,
  start_time TIME NOT NULL,
  end_time TIME NOT NULL,
  status ENUM('pending', 'confirmed', 'cancelled', 'completed') NOT NULL DEFAULT 'pending',
  source ENUM('web', 'line', 'phone', 'direct') NOT NULL,
  payment_status ENUM('unpaid', 'paid', 'refunded') NOT NULL DEFAULT 'unpaid',
  payment_amount INT NULL,
  coupon_code VARCHAR(50) NULL,
  notes TEXT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at DATETIME NULL,
  PRIMARY KEY (id),
  KEY idx_reservations_store (store_id),
  KEY idx_reservations_date (reservation_date),
  KEY idx_reservations_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### cleaning_jobs（清掃案件）
```sql
CREATE TABLE cleaning_jobs (
  id BIGINT NOT NULL AUTO_INCREMENT,
  reservation_id BIGINT NOT NULL,
  store_id BIGINT NOT NULL,
  sales_area_id BIGINT NOT NULL,
  scheduled_at DATETIME NOT NULL,
  status ENUM('unassigned', 'recruiting', 'assigned', 'completed', 'paid') NOT NULL DEFAULT 'unassigned',
  assigned_cleaner_id BIGINT NULL,
  base_reward INT NOT NULL DEFAULT 0,
  extension_reward INT NOT NULL DEFAULT 0,
  notes TEXT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at DATETIME NULL,
  PRIMARY KEY (id),
  KEY idx_cleaning_jobs_status (status),
  KEY idx_cleaning_jobs_scheduled (scheduled_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### cleaners（清掃者）
```sql
CREATE TABLE cleaners (
  id BIGINT NOT NULL AUTO_INCREMENT,
  line_user_id VARCHAR(255) NOT NULL,
  name VARCHAR(100) NOT NULL,
  phone VARCHAR(20) NULL,
  is_active TINYINT(1) NOT NULL DEFAULT 1,
  registered_at DATETIME NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted_at DATETIME NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_cleaners_line (line_user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 5.4 設計方針

- **論理削除**: 全テーブルに `deleted_at` を持ち、物理削除は行わない
- **日時管理**: 全てJST（Asia/Tokyo）で保存、DATETIME型使用
- **ENUM**: ステータス系はENUM型で厳密に管理
- **JSON型**: 動的設定は `settings` カラム（JSON型）で柔軟に対応
