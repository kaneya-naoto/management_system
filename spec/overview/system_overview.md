# システム概要

## システム名

**カクレマ 新基幹システム**

---

## コンセプト

個室麻雀店「カクレマ」専用の予約・清掃業務・人員管理システム

### 主要目的

1. **属人化の排除**: 予約・清掃業務・人員管理のオペレーションを標準化
2. **店舗単位CMS**: FC展開を前提とした店舗単位で完結するCMS基盤
3. **LINE自動化**: 清掃募集/延長対応/急募対応をLINEで自動化

---

## ビジネス要件

### 予約管理
- **Web予約**: サイトフォーム → **予約即確定**（MVP版: 決済なし） → CMS自動反映
- **その他予約**: LINE/電話 → スタッフがCMSへ手動入力
- **予約完了**: 確認メール送信、メールアドレス修正・再送機能

> **MVP方針**: 現行版はオンライン決済を組み込まず、予約フォーム送信で即確定とする。決済連携は将来フェーズで導入予定。

### 清掃案件管理
- 予約確定時に清掃案件を**自動生成**
- LINE連携で清掃者を募集
- 状態遷移: `unassigned` → `recruiting` → `assigned` → `completed` → `paid`

### 鍵番号管理
- 区分ごとに複数の鍵番号を登録（例：10個）
- 予約確定時にランダム割当
- **同一時間帯の競合防止**（悲観的ロック）

### 固定者・急募
- 固定者へ優先通知 → NG時はLINE公募
- 条件該当（固定者NG/延長NO/未充足）で【急募】Push配信

### 延長対応
- 店舗設置QR → 延長フォーム → 担当者通知
- YES: 案件更新（時間・報酬）
- NO: 急募通知へ
- **報酬計算**: 延長1時間ごとに基本報酬の50%加算

### 支払い管理
- 案件単位: 担当者、基本報酬、延長加算、支払いステータス
- 店舗単位で集計・確認

### 売上・KPI
- 区分別集計: 売上/稼働率/清掃コスト/粗利
- 予約経路別の集計
