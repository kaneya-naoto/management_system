# 組織階層・権限モデル

## 組織階層

組織は固定の3階層構造（拠点・エリア概念なし）：

```
統括本部
└── オーナー（契約・請求主体）
    └── 実店舗（CMS 1つ = 1店舗）
        └── 内部営業区分（店舗区分）
            - 例：池袋東口
            - 例：池袋東口プレミアム
```

### 内部営業区分の設計意図

- 売上・予約・案件・鍵番号を**区分別に管理・集計**
- 将来的に「独立店舗」に**昇格可能なID設計**を前提
- FC展開時のデータ分離性を担保

## 権限モデル（3階層）

| レベル | 種別 | 英語名 | 操作範囲 |
|--------|------|--------|----------|
| 3 | 統括本部 | HQ | 全店舗 |
| 2 | オーナー | OWNER | 自オーナー配下店舗 |
| 1 | 店舗 | STORE | 自店舗のみ |

### 権限詳細

#### 統括本部（HQ）
- 全オーナー・全実店舗の切替表示
- 全設定・全ログ閲覧
- 監査・サポート業務

#### オーナー（OWNER）
- 自オーナー配下の実店舗のみ切替表示
- 店舗設定・運用管理
- 請求・支払いの閲覧（必要に応じ編集）

#### 店舗（STORE）
- 自店舗のみ
- 予約・案件・シフト・固定者・支払い管理

### 現行の権限運用

現状は3階層ロール（HQ / OWNER / STORE）のみで運用する。
操作種別（表示・編集・設定）の細分化は行わず、ロールレベルでアクセス制御する。

> **将来拡張**: 必要に応じて表示可/編集可/設定可の権限分離を導入可能な設計とする。

## 認証方式

### CMS側（管理画面）

| 項目 | 内容 |
|------|------|
| 認証方法 | メール + パスワード |
| パスワードリセット | メールでリンク送信 |
| セッション管理 | PHPセッション |
| パスワードハッシュ | bcrypt (cost=12) |

### 清掃者（LINE）

| 項目 | 内容 |
|------|------|
| 識別方法 | LINE UserID（自動識別） |
| 初回登録 | プロフィール登録必須 |
| 2回目以降 | 自動認識（iPass入力でも可） |

## 認可チェックの実装方針

```
role × scope の組み合わせで判定
```

### 例: 予約一覧の取得

```php
// HQ: 全店舗
// OWNER: 自オーナー配下店舗（owner_id でフィルタ）
// STORE: 自店舗のみ（store_id でフィルタ）
```

### 実装ファイル

認証・認可は **`includes/auth.php`** に統合して実装している（クラスベースではなく関数ベース）。

| 関数 | 責務 |
|------|------|
| `login()` / `logout()` | ログイン・ログアウト処理 |
| `isLoggedIn()` / `requireLogin()` | ログイン状態チェック |
| `currentUser()` / `getCurrentUserId()` | ログインユーザー情報取得（リクエスト内キャッシュ付き） |
| `hasRole()` / `requireRole()` | 3階層ロールチェック（HQ > OWNER > STORE） |
| `canAccessStore()` / `requireStoreAccess()` | 店舗アクセス権チェック |
| `getAccessibleStoreIds()` | アクセス可能な店舗ID一覧取得 |
| `setSelectedStore()` / `getSelectedStore()` | 店舗選択のセッション管理 |
| `getFilteredStoreIds()` | クエリ用の店舗IDフィルタ取得 |
| `generateCsrfToken()` / `verifyCsrfToken()` / `requireCsrf()` | CSRFトークン管理 |
| `hashPassword()` | パスワードハッシュ生成（bcrypt） |
| `isLoginLocked()` / `recordLoginAttempt()` | ログイン試行制限（DBベース・IP単位） |

> **設計判断**: FWなしのPHPプロジェクトのため、クラス分離（Auth + AuthzService）ではなく単一ファイルに関数群として統合。認証・認可・CSRF・ブルートフォース対策をまとめて管理する。
