# 予約管理UI（CMS）

## 概要

CMSでの予約管理画面の仕様

---

## 予約一覧

### 表示形式

| 形式 | 説明 |
|------|------|
| 月間表示 | カレンダー形式で月単位表示 |
| ガント表示 | 時間軸で予約状況を可視化 |
| リスト表示 | 一覧形式で詳細表示 |

### フィルタ

| フィルタ | 選択肢 |
|----------|--------|
| 店舗区分 | 全て / 各営業区分 |
| ステータス | 全て / 保留 / 確定 / 完了 / キャンセル |
| 期間 | 日付範囲指定 |
| 予約経路 | 全て / Web / LINE / 電話 / 直接 |

### 一覧カラム

| カラム | 説明 |
|--------|------|
| 予約日 | 利用日 |
| 時間 | 開始〜終了 |
| 顧客名 | 予約者名 |
| 区分 | 営業区分名 |
| ステータス | 予約状態 |
| 鍵番号 | 割当済みの場合表示 |
| 経路 | 予約流入経路 |
| 操作 | 詳細/編集/キャンセル |

## 手動予約登録

### 入力フォーム

| 項目 | 必須 | 入力タイプ |
|------|------|------------|
| 営業区分 | ○ | セレクトボックス（店舗名 - 区分名） |
| 予約日 | ○ | 日付ピッカー（デフォルト当日） |
| 開始時間 | ○ | 時刻入力（デフォルト10:00） |
| 終了時間 | ○ | 時刻入力（デフォルト12:00） |
| 予約経路 | ○ | セレクト（電話/LINE/直接来店/Web予約） |
| 顧客名 | ○ | テキスト（最大100文字） |
| 電話番号 | - | テキスト（最大20文字、任意） |
| メールアドレス | - | テキスト（メール形式、任意） |
| 人数 | - | 数値（1〜10、デフォルト1） |
| 基本料金 | - | 数値（0〜1000万円、デフォルト5000） |
| 決済状態 | - | セレクト（未払い/支払済、デフォルト未払い） |
| 備考 | - | テキストエリア（最大1000文字） |

> **注**: 電話番号・メールアドレスはCMS手動登録では任意。公開予約フォームでは必須。
> 決済状態を「支払済」にすると、予約確定（confirmed）+ 鍵割当 + 清掃案件が自動生成される。

### バリデーション

| ルール | エラーメッセージ |
|--------|------------------|
| 開始時刻 < 終了時刻 | 終了時刻は開始時刻より後にしてください（深夜跨ぎは18時以降開始・6時以前終了に限り許可） |
| 過去日付の予約 | 警告なし（CMS手動登録では過去日付も登録可能） |
| メール形式（入力時のみ） | メールアドレスの形式が正しくありません |
| 顧客名100文字超 | 顧客名は100文字以内で入力してください |
| 電話番号20文字超 | 電話番号は20文字以内で入力してください |
| 人数1〜10の範囲外 | 人数は1〜10人で指定してください |
| 基本料金0〜1000万円外 | 基本料金は0〜1000万円の範囲で入力してください |
| 備考1000文字超 | 備考は1000文字以内で入力してください |
| 必須項目未入力 | {項目名}は必須です |

## 予約詳細・編集

### 表示項目

- 基本情報（日時、顧客、区分）
- ステータス履歴
- 鍵番号割当情報
- 関連する清掃案件へのリンク
- 決済情報（金額、ステータス）

### 編集可能項目

| 項目 | 編集可否 | 条件 |
|------|----------|------|
| 顧客名 | ○ | - |
| メールアドレス | ○ | - |
| 電話番号 | ○ | - |
| 日時 | ○ | 確定前のみ |
| 営業区分 | △ | 確定前のみ |
| 備考 | ○ | - |

---

## ステータス操作

### 操作ボタン

| 操作 | 条件 | 結果 |
|------|------|------|
| 確定 | pending時 | confirmed + 鍵割当 + 案件生成 |
| キャンセル | confirmed以前 | cancelled |
| 完了 | confirmed時 | completed |

### キャンセル処理

1. 予約ステータスを `cancelled` に変更
2. 鍵割当を解除
3. 清掃案件をキャンセル状態に
4. キャンセル通知メール送信（オプション）

---

## 権限による表示制御

| 権限 | 表示範囲 |
|------|----------|
| HQ | 全店舗の予約 |
| OWNER | 配下店舗の予約 |
| STORE | 自店舗の予約のみ |
