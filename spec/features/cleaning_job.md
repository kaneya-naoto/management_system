# 清掃案件管理

## 概要

予約確定時に自動生成される清掃案件の管理機能

---

## 案件生成（自動）

### トリガー

予約ステータスが `confirmed` に変更された時点で自動生成

### 生成される案件データ

| 項目 | 値 |
|------|-----|
| reservation_id | 元の予約ID |
| store_id | 予約の店舗ID |
| sales_area_id | 予約の営業区分ID |
| scheduled_at | 予約終了時刻（清掃開始予定） |
| status | unassigned（未割当） |
| base_reward | 店舗/区分設定から取得 |

### 生成フロー

```
[予約確定]
    ↓
[案件生成] cleaning_jobsにレコード作成
    ↓
[固定者チェック] 該当区分に固定者がいるか
    ↓
┌─ YES ─→ [固定者通知] 優先通知を送信
│                ↓
│          [応答待ち] OK/NGを待機
│                ↓
│          ┌─ OK ─→ [担当確定] assignedへ
│          │
│          └─ NG ─→ [公募開始] recruitingへ
│
└─ NO ──→ [公募開始] recruitingへ → [LINE通知]
```

---

## ステータス遷移

```
unassigned ──→ recruiting ──→ assigned ──→ completed ──→ paid
     │              │              │
     │              └──────────────┘
     │              （応募あり時は直接遷移可）
     │
     └──→ recruiting
          （固定者NGの場合）
```

### 各ステータスの説明

| ステータス | DB値 | 日本語 | 説明 |
|------------|------|--------|------|
| 未割当 | unassigned | 未割当 | 案件生成直後 |
| 募集中 | recruiting | 募集中 | LINE公募中 |
| 確定 | assigned | 確定 | 担当者決定 |
| 完了 | completed | 完了 | 清掃完了報告済み |
| 支払済 | paid | 支払済 | 報酬支払処理済み |

## CMS画面

### 案件一覧

| カラム | 説明 |
|--------|------|
| 予定日時 | scheduled_at |
| 店舗 | 店舗名 + 営業区分名（サブテキスト） |
| ステータス | 案件状態（バッジ表示） |
| 担当者 | 確定時に表示、未割当時は「-」 |
| 応募数 | 応募者数（バッジ表示、0件時は「-」） |
| 報酬 | base_reward |
| 操作 | 詳細ボタン |

### フィルタ

| フィルタ | 選択肢 |
|----------|--------|
| ステータス | 全て / 各ステータス |
| 期間 | 日付範囲 |
| 営業区分 | 全て / 各区分 |
| 担当者 | 全て / 未割当 / 担当者名 |

### 詳細画面

- 案件基本情報（予定日時、店舗、営業区分、種別、報酬、備考）
- 担当者情報（名前、電話番号、清掃者詳細リンク）
- 応募者一覧（清掃者名、実績件数、応募日時、ステータス、採用ボタン）
- 延長履歴（延長時間、ステータス、登録日時）
- 関連予約情報（顧客名、予約日時、予約詳細リンク）
- 通知ステータス（固定者応答待ち / 公募中 / 完了）

#### サイドバー操作

- **ステータス変更**: ドロップダウンで任意のステータスに変更可能
- **LINE通知**: 募集開始（固定者優先）/ 公募で開始 / 急募通知送信
- **報酬設定**: 基本報酬の手動変更
- **延長登録**: 0.5〜5時間（0.5刻み）の延長を追加

---

## 手動操作

### 担当者割当

募集中でも管理者が手動で担当者を割り当て可能：

1. 案件詳細画面を開く
2. 「担当者を割り当て」ボタン
3. 清掃者を検索・選択
4. 確認 → ステータスが `assigned` に変更

### ステータス変更

| 操作 | 条件 | 結果 |
|------|------|------|
| 公募開始 | unassigned時 | recruitingへ |
| 担当確定 | recruiting時 | assignedへ |
| 完了 | assigned時 | completedへ |
| 支払済 | completed時 | paidへ |

---

## 急募条件

以下のいずれかに該当すると【急募】通知をPush配信：

| 条件 | 説明 |
|------|------|
| 固定者NG | 固定者が全員辞退 |
| 延長NO | 延長依頼を担当者が拒否 |
| 未充足 | 清掃予定時刻の2時間前でも未割当 |

---

## 報酬計算

### 基本報酬

`base_reward` は店舗/区分の設定値から取得

### 延長報酬

延長時の清掃報酬は **常に0**。延長しても清掃者への報酬は変わらない。

> 014マイグレーション（014_reset_extension_rewards.sql）で既存データもリセット済み。
> 延長料金は顧客請求のみに適用され、清掃者報酬には影響しない。

### 総報酬

```
total_reward = base_reward（延長報酬は常に0のため、実質 base_reward のみ）
```
