# 清掃時間を考慮した予約・延長制約 仕様書

## 概要

予約終了後に清掃時間（1時間）が必要なため、予約の作成・延長時にこの時間を考慮した制約を設ける。

---

## 基本ルール

```
予約終了時刻 + 清掃時間（1時間） <= 次の予約開始時刻
```

### 例

| 現在の予約終了 | 清掃終了 | 次の予約開始可能 |
|--------------|---------|----------------|
| 20:00 | 21:00 | 21:00以降 |
| 22:00 | 23:00 | 23:00以降 |
| 23:00 | 24:00 | 24:00（翌0:00）以降 |

---

## 影響範囲

### 1. 予約フォーム（新規予約作成）

**ファイル**: `public_html/pages/booking/*.php`

**制約**:
- 選択した開始時刻は、前の予約の終了時刻 + 1時間以降であること
- 終了時刻は、次の予約の開始時刻 - 1時間以前であること

**例**:
```
既存予約: 14:00-16:00
↓
新規予約可能: 17:00以降開始（16:00終了 + 1時間清掃）
```

### 2. 延長申請フォーム

**ファイル**: `public_html/pages/extend/index.php`

**制約**:
- 延長後の終了時刻 + 1時間 <= 次の予約開始時刻
- 延長後の終了時刻 <= 閉店時刻（24時間営業でない場合）

**例**:
```
現在の予約: 20:00-22:00
次の予約: 24:00開始
↓
延長可能: 最大1時間（23:00まで）
理由: 23:00終了 + 1時間清掃 = 24:00 = 次の予約開始
```

### 3. 管理画面からの予約作成・編集

**ファイル**: `public_html/pages/reservations/create.php`

同様の制約を適用。

## 延長申請の詳細仕様

### 延長可能時間の計算

```php
// 次の予約を取得
$nextReservation = getNextReservation($salesAreaId, $currentEndTime);

// 閉店時刻を取得
$closingTime = getStoreClosingTime($storeId);

// 延長可能な最大終了時刻を計算
if ($nextReservation) {
    // 次の予約がある場合: 次の予約開始 - 清掃時間
    $maxEndTime = $nextReservation['start_time'] - 1時間;
} else {
    // 次の予約がない場合: 閉店時刻
    $maxEndTime = $closingTime;
}

// 延長可能時間 = 最大終了時刻 - 現在の終了時刻
$availableExtension = $maxEndTime - $currentEndTime;
```

### 表示する選択肢

延長可能時間に応じて選択肢を動的に表示：

| 延長可能時間 | 表示する選択肢 |
|------------|--------------|
| 2時間以上 | 30分, 1時間, 1時間30分, 2時間 |
| 1時間30分〜2時間未満 | 30分, 1時間, 1時間30分 |
| 1時間〜1時間30分未満 | 30分, 1時間 |
| 30分〜1時間未満 | 30分 |
| 30分未満 | 延長不可（メッセージ表示） |

### エラーメッセージ

| 状況 | メッセージ |
|------|----------|
| 次の予約があり延長不可 | 「次のご予約があるため、延長できません」 |
| 閉店時間で延長不可 | 「閉店時間のため、延長できません」 |
| 延長可能時間が短い | 「最大○分まで延長可能です」 |

## 営業時間の考慮

### 通常営業（例: 10:00〜22:00）

- 延長後の終了時刻 <= 22:00

### 深夜営業（例: 10:00〜翌2:00）

- 日をまたぐ場合の処理が必要
- 終了時刻が翌日の場合: 26:00 として計算（または DateTime で処理）

### 24時間営業

- 閉店時間チェックはスキップ
- 次の予約チェックのみ適用

## データベース参照

### 次の予約の取得クエリ

```sql
SELECT r.id, r.start_time, r.end_time
FROM reservations r
WHERE r.sales_area_id = :sales_area_id
  AND r.reservation_date = :date
  AND r.start_time > :current_end_time
  AND r.status IN ('confirmed', 'pending')
  AND r.deleted_at IS NULL
ORDER BY r.start_time ASC
LIMIT 1
```

### 店舗営業時間の取得

```sql
SELECT is_24h_open, opening_time, closing_time
FROM stores
WHERE id = :store_id
```

## テスト項目

### 延長申請

1. [ ] 次の予約がない場合、閉店時間まで延長可能
2. [ ] 次の予約がある場合、開始1時間前まで延長可能
3. [ ] 延長可能時間に応じた選択肢のみ表示される
4. [ ] 延長不可の場合、適切なメッセージが表示される
5. [ ] 24時間営業店舗で閉店チェックがスキップされる

### 予約フォーム

1. [ ] 前の予約終了後1時間以内の開始時刻が選択できない
2. [ ] 次の予約開始1時間前以降の終了時刻が選択できない
3. [ ] 空き状況表示に清掃時間が反映されている
