# シフト管理

## 概要

案件と清掃者をマージ表示し、シフト状況を一覧で確認する機能

---

## シフト表示

### 表示形式

日別のタイムライン表示で、清掃者ごとの稼働状況を可視化

```
2026-01-30（木）

        | 10:00 | 11:00 | 12:00 | 13:00 | 14:00 | 15:00 |
--------+-------+-------+-------+-------+-------+-------+
山田    | ■■■■■■■■■■ |       | ■■■■■ |       |
田中    |       | ■■■■■■■■■■■■■■■ |       |
佐藤    |       |       |       | ■■■■■■■■■■ |
未割当  |       |       | ●●●●● |       |       |
```

### 表示要素

| 要素 | 説明 |
|------|------|
| ■ | 担当確定の案件 |
| ● | 未割当（募集中）の案件 |
| 色分け | 営業区分ごとに色を変更 |

---

## CMS画面

### シフト一覧

| カラム | 説明 |
|--------|------|
| 日付 | シフト日 |
| 時間 | 開始〜終了 |
| 営業区分 | 案件の区分 |
| 担当者 | 確定時に表示 |
| ステータス | 案件状態 |
| 報酬 | 基本 + 延長 |

### フィルタ

| フィルタ | 選択肢 |
|----------|--------|
| 期間 | 日付範囲（デフォルト: 今日〜7日後） |
| 営業区分 | 全て / 各区分 |
| ステータス | 全て / 未割当 / 募集中 / 確定 |
| 清掃者 | 全て / 清掃者名 |

---

## 未応募・未充足の可視化

### アラート表示

| 条件 | 表示 |
|------|------|
| 未割当（案件生成直後） | 黄色マーク |
| 募集中（2時間以内） | 赤色マーク（急募候補） |
| 募集中（それ以外） | オレンジマーク |

### 一覧での強調

```
⚠️ 14:00〜 池袋東口 [募集中] ← 1時間後！
```

## 担当者の割当

### シフト画面からの操作

1. 未割当/募集中の案件をクリック
2. 清掃者選択モーダルが開く
3. 対応可能な清掃者を選択
4. 確認 → 担当確定

### 対応可能な清掃者の条件

- 該当店舗に登録済み（cleaner_stores）
- `is_active = true`
- 同時間帯に他の案件なし

---

## シフト変更

### 担当者の変更

1. 確定済みの案件をクリック
2. 「担当者変更」ボタン
3. 新しい清掃者を選択
4. 変更理由を入力（任意）
5. 確認 → 変更完了

### 変更時の処理

- 元担当者にキャンセル通知
- 新担当者に確定通知
- 変更履歴をaudit_logsに記録
