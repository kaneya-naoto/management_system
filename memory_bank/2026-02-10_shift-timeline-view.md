# シフト管理画面 タイムライン表示追加

**実施日**: 2026-02-10
**対象機能**: シフト管理画面（`/shifts`）にガントチャート風タイムライン表示を追加

---

## 概要

シフト管理画面にテーブル表示とタイムライン表示の切替機能を実装。
タイムラインでは案件を時間軸上のバーとして可視化し、3種類のグルーピング（日付・営業区分・清掃者）に対応。

## 実装内容

### 1. ビュー切替（テーブル ⇔ タイムライン）
- クエリパラメータ `view=table`（デフォルト） / `view=timeline`
- `.period-tabs` コンポーネント再利用（サーバーサイド切替）
- フィルタフォームに `view` を hidden で保持し、フィルタ変更時もビューを維持

### 2. 統一タイムラインレイアウト
- **当初**: 日付ごとにカード分離 → **ユーザーフィードバックで修正**: 全日付を1つのタイムラインに統合
- 時間軸: 6:00〜26:00（翌2:00）= 20時間
- メジャーティック: 30分間隔のラベル表示
- マイナーライン: 15分位置に薄い罫線
- CSS Grid + absolute positioning ハイブリッド方式

### 3. 3種類のグルーピング（JS切替 + history.replaceState）
| モード | グループ行 | バー内表示 |
|--------|-----------|-----------|
| 日付 | 日付（月/日 曜日） | 営業区分名 + 担当者名 |
| 営業区分 | 営業区分名 > 日付 | 担当者名 |
| 清掃者 | 清掃者名 > 日付 | 営業区分名 |

### 4. レーンスタッキング（重なり処理）
- グリーディ区間スケジューリングアルゴリズム
- 同一グループ内で時間が重なるバーをサブレーン（段）に分離
- 重なり数に応じて行の高さを動的拡張（1段=36px × n段）

### 5. バーの色分け + アクセシビリティ
| ステータス | 色 | アイコン |
|-----------|-----|---------|
| 未割当 | グレー | `bi-dash-circle` |
| 募集中 | 黄色 | `bi-megaphone` |
| 確定 | 青 | `bi-check-circle` |
| 完了 | 緑 | `bi-check-circle-fill` |
| 支払済 | シアン | `bi-check-circle-fill` |
| キャンセル | 赤（半透明＋取消線） | `bi-x-circle` |
| 急募 | 赤左ボーダー | `bi-exclamation-triangle` |

### 6. ツールチップ（ホバー）
- 単一 `<div>` 要素をイベント委譲で管理
- 表示内容: 営業区分名、時間帯、ステータス、担当者、報酬
- `position: fixed` でビューポート基準配置、画面外自動回避

### 7. 現在時刻ライン
- 当日の行のみに赤い縦線を表示

### 8. レスポンシブ対応
- デスクトップ: フル表示、ラベル列 sticky
- モバイル（767.98px以下）: 横スクロール対応、スクロールヒント表示

## セキュリティ対策

- JSON出力: `JSON_HEX_TAG | JSON_HEX_AMP | JSON_HEX_APOS | JSON_HEX_QUOT` + 失敗時フォールバック
- HTMLエスケープ: `esc()` 関数（キャッシュ済み `_escDiv` 使用）
- イベント委譲でバークリック・ツールチップを処理
- `view` / `group` パラメータのホワイトリスト検証

## パフォーマンス対策

- `DocumentFragment` でバッチDOM挿入
- イベント委譲（バーごとにリスナーを付けない）
- ツールチップは単一要素を使い回し
- `esc()` 関数は `_escDiv` をキャッシュ

## バグ修正履歴

### 1. `_escDiv` 未定義エラー
- **症状**: `Uncaught TypeError: Cannot set properties of undefined (setting 'textContent')`
- **原因**: `var _escDiv` がIIFE末尾で宣言されていたが、`renderAll()` が先に呼ばれた（`var` はホイストされるが初期化はされない）
- **修正**: `_escDiv` の初期化をIIFE先頭（`container` 変数宣言直後）に移動

### 2. `recruiting` ラベルが英語表示
- **症状**: ステータスバッジに "recruiting" と英語で表示
- **原因**: `jobStatusLabel()` に `recruiting` ケースがなく、`default` で生の文字列が返された
- **修正**: `'recruiting' => ['label' => '募集中', 'class' => 'warning']` を追加

### 3. 深夜跨ぎ時間計算（コードレビューで発見）
- **症状**: 23:00→07:00 のシフトでバー幅が0になる
- **原因**: `e=420 < s=1380` で負の幅が計算される
- **修正**: `if (e <= s) e += 24 * 60;` を `computeLanes()` と `createBar()` の両方に追加
